account_tree Architecture & SOLID Design Principles Matrix

ENTERPRISE AUDIT
S Single Responsibility Principle (SRP)

A class should have only one reason to change. The AI highlights god classes and separates concerns (e.g. moving email dispatch out of user registration into a dedicated NotificationService).

D Dependency Inversion Principle (DIP)

High-level modules should not depend on low-level modules; both should depend on abstractions. Flags direct new Class() calls in domain services and recommends Constructor Dependency Injection.

P Performance & N+1 Loop Prevention

Detects asynchronous operations and database queries inside synchronous loops, recommending batch loading via Promise.all() or single SQL multi-item fetch queries.

X Security & SQL Injection (CWE-89)

Flags raw SQL string concatenations and template literals in query arguments, enforcing parameterized queries or ORM queries.
